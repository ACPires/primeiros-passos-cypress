# My Cypress Automation

This project utilizes Cypress to automate the testing of login and user update features.
Cypress is a JavaScript-based end-to-end testing framework that allows developers to write tests and execute them in a real browser.


## Installation

```bash
npm install
```
> **NOTE**
>
> It is necessary to have **node** installed

## Running

```bash
# To open the Cypress UI
npx cypress open

#To run the automation by command line
npx cypress run
```
